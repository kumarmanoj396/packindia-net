# PACK INDIA — Phase 1

Next.js 16 / React 19 / TypeScript starter for the PACK INDIA packaging website at `packindia.net`.

## Included
- Home
- About Us
- Products
- Product detail pages
- Services
- Contact Us
- Shared header/footer
- Responsive desktop/tablet/mobile styling
- Centralized product data
- Quote and enquiry CTAs

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Phase 1 notes
The visual structure follows the supplied PACK INDIA reference snapshot: navy + orange brand palette, corporate packaging layout, product cards, trust strip, enquiry CTA and inner pages.

Replace placeholder product artwork with the client's actual product/warehouse photographs and update company contact details before production deployment.
