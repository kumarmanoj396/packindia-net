# Memory Bank

This directory stores concise, repository-scoped context for maintainers and coding agents. Keep entries factual, current, and close to the code. Update a note when a verified project convention changes.

## Notes

- [Project context](project-context.md): stack, purpose, routes, and current product scope
- [Architecture](architecture.md): ownership of pages, components, data, and integrations
- [Agent guide](agent-guide.md): editing, validation, and change-management rules

These notes supplement the README; they do not replace source code or deployment configuration.
